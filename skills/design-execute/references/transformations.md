# Turn a design reaction into a useful change

Use this when the request is a direction such as bolder, quieter, more playful or more refined. Infer the dissatisfaction from the artifact and the user's reason. Preserve the content, behaviour and successful relationships unless the request changes them.

| Intent | Productive choices | Common misreading |
| --- | --- | --- |
| Bolder | Increase a meaningful contrast in scale, composition, type character or interaction | Increase every saturation, shadow and font size |
| Quieter | Reduce competing emphasis while retaining a clear focal point | Flatten the hierarchy or lower readable contrast |
| More distinctive | Develop a visual or behavioural idea from the subject | Add an unrelated fashionable effect |
| More delightful | Improve feedback, continuity or a rewarding discovery | Delay frequent actions with repeated animation |
| Distil | Remove a competing job or redundant structure | Hide essential information or navigation |
| Refine | Correct optical balance, rhythm, type detail and state consistency | Make arbitrary pixel edits without a visible reason |
| Harden | Resolve real-content, loading, error, input and viewport edge cases | Redesign the visual language |

When the intent is clear, choose the change that best addresses it. When two interpretations would produce meaningfully different results, show a small comparison or ask one decisive question. The number of variants should answer the uncertainty, not satisfy a quota. Borrow these lenses selectively; they are not a mandatory sequence.

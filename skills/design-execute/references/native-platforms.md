# Native platform routing

Use for native or genuinely platform-adaptive apps. Start from the target platform and the user's activity rather than transplanting a web layout. Read only the relevant reference below. Verify current official guidance when APIs or platform conventions affect the implementation.

- [iOS and iPadOS](native-ios.md): safe areas, navigation, sheets, type growth, gestures and platform accessibility.
- [Android and adaptive windows](native-android.md): insets, system Back, window classes, panes, input modes and state continuity.

Keep the product's identity in composition, content and visual language. Native controls are a useful baseline, not an instruction to make every app look identical. Desktop, web and native surfaces can share concepts without sharing every interaction.

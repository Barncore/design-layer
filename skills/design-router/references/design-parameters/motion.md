# Motion & time

How objects arrive, react, remain connected and get out of the way.

Use these dimensions to make project-specific choices. The alternatives are examples to combine or extend, not scores or required opposites. Choose from the brief and inspect the consequences; the user does not need to answer each dimension.

## motion-01: Easing character

**Alternatives:** Linear / decelerating / elastic / stepped

**What changes:** The same distance and duration can feel mechanical, direct or playful.

**Apply to the brief:** Choose speed change and settling character for the object, action and intended feel; compare variants at the same distance before attributing the difference to duration.

## motion-02: Duration and distance

**Alternatives:** Brief local response / longer spatial move

**What changes:** Time should be judged with travel distance and frequency of use.

**Apply to the brief:** Judge time together with travel distance, attention and repetition; let the task and project determine how much the movement should be noticed.

## motion-03: Origin

**Alternatives:** From the control / from an edge / from nowhere

**What changes:** A visible origin can connect an action with its result.

**Apply to the brief:** Connect movement to a trigger or spatial boundary when that explains cause; use an unexpected origin only when it serves the intended experience.

## motion-04: Continuity

**Alternatives:** Same object transforms / replacement / cut

**What changes:** A shared object can carry orientation across state changes.

**Apply to the brief:** Preserve apparent object identity when it helps orientation, or use a deliberate cut or replacement when the change of context is the point.

## motion-05: Choreography

**Alternatives:** Together / staggered / sequential

**What changes:** Order and overlap determine the rhythm of a group.

**Apply to the brief:** Coordinate order and overlap to direct attention and express relationships; check the complete sequence for accumulated delay and readability.

## motion-06: Interruption

**Alternatives:** Finish first / redirect immediately

**What changes:** Try reversing or clicking again before the transition completes.

**Apply to the brief:** Handle reversal and repeated input from the visible state; an intentional committed transition still needs understandable feedback and appropriate recovery.

## motion-07: Rest and activity

**Alternatives:** Still at rest / ambient movement / responsive only

**What changes:** Constant motion competes with reading in a different way from interaction-triggered motion.

**Apply to the brief:** Choose ambient, responsive or still behaviour by the role of each region; preserve readable content and the relevant reduced-motion controls.

## motion-08: Repetition tolerance

**Alternatives:** First encounter / occasional / every action

**What changes:** An entertaining entrance can become friction on the hundredth visit.

**Apply to the brief:** Evaluate the same effect across likely repeat visits and rapid use; a rich motion language can remain appropriate when responsiveness and the brief support it.

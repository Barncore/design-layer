# Adaptation & limits

How the identity survives new sizes, inputs, states and abilities.

Use these dimensions to make project-specific choices. The alternatives are examples to combine or extend, not scores or required opposites. Choose from the brief and inspect the consequences; the user does not need to answer each dimension.

## adaptation-01: Recomposition

**Alternatives:** Shrink / rearrange / change the presentation

**What changes:** A narrow screen may need a new relationship between objects.

**Apply to the brief:** Preserve the defining visual and functional relationships across sizes, even when that requires recomposition or a different presentation rather than shrinkage.

## adaptation-02: Input mode

**Alternatives:** Pointer / touch / keyboard / assistive input

**What changes:** A hover flourish is one experience among several.

**Apply to the brief:** Provide equivalent task access and intelligible feedback across pointer, touch, keyboard and assistive input; a hover effect is only one expression.

## adaptation-03: Text variability

**Alternatives:** Ideal copy / long labels / larger type

**What changes:** Real text exposes the difference between a composition and a fragile picture.

**Apply to the brief:** Test real variation in copy, labels, language and text size; let the composition adapt while its important hierarchy survives.

## adaptation-04: Reduced effects

**Alternatives:** Full motion / restrained alternative / immediate state

**What changes:** A quieter version can retain identity and meaning.

**Apply to the brief:** Identify the meaning and identity that must survive reduced motion, transparency or other effects; design the alternate presentation deliberately.

## adaptation-05: Performance character

**Alternatives:** Immediate core / progressive atmosphere

**What changes:** An elaborate scene can arrive after the interface becomes useful.

**Apply to the brief:** Make essential interaction useful at the appropriate time and stage optional atmosphere according to the project’s performance needs; verify cost on representative devices.

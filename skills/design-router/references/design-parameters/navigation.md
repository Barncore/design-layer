# Navigation & space

Whether the interface feels like a document, index, instrument or place.

Use these dimensions to make project-specific choices. The alternatives are examples to combine or extend, not scores or required opposites. Choose from the brief and inspect the consequences; the user does not need to answer each dimension.

## navigation-01: Interface topology

**Alternatives:** Document / index / canvas / world

**What changes:** These structures invite different ways of finding and comparing things.

**Apply to the brief:** Choose document, index, canvas or world according to how the audience should locate, compare or inhabit the content; novelty alone does not determine topology.

## navigation-02: View switching

**Alternatives:** One presentation / list-grid-map alternatives

**What changes:** Different views can reveal different relationships in the same content.

**Apply to the brief:** Provide another view when it reveals a useful relationship in the same content; preserve selection, identity and orientation when switching.

## navigation-03: Orientation

**Alternatives:** Persistent landmarks / minimap / breadcrumbs / none

**What changes:** Spatial novelty needs a way to know where you are and return.

**Apply to the brief:** Keep suitable landmarks or return routes available as the spatial model becomes less familiar; test whether users can identify location and get back.

## navigation-04: Disclosure depth

**Alternatives:** All visible / progressive / inline expansion

**What changes:** Revealing detail locally can preserve context or create too much nesting.

**Apply to the brief:** Use disclosure to manage complexity while retaining useful context; examine whether nested detail helps investigation or makes information hard to recover.

## navigation-05: Navigation position

**Alternatives:** Fixed edge / content-adjacent / contextual

**What changes:** Where navigation lives affects the composition and reach.

**Apply to the brief:** Place navigation where its relationship to content and reach is clear; assess persistent framing against the space it consumes on smaller screens.

## navigation-06: Mode boundaries

**Alternatives:** Stable workspace / explicit modes / fluid transformation

**What changes:** Mode changes can reduce clutter but hide available actions.

**Apply to the brief:** Use modes when they clarify a task or reduce competing controls; make the active mode and available transitions understandable.

## navigation-07: Alternate path

**Alternatives:** Experiential route / direct index / search

**What changes:** An expressive entrance and a quick route can coexist.

**Apply to the brief:** Pair an experiential route with a direct index or search when repeat visitors need efficient access; make the important quick path discoverable.
